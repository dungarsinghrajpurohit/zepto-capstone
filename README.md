# Zepto Data & AI Platform (Capstone Project)

Welcome to the **Zepto Data & AI Platform** repository.

## 📁 Repository Structure
- **data_pipeline/** : Module 1 - Web Scraping, SQLite Database & Verification
- **analytics/** : Module 2 - Data Profiling, Feature Engineering & Predictive Modeling
- **support_assistant/** : Module 3 - Grounded GenAI Support Assistant (8 Policies)

## 🚀 Modules Summary
1. **Module 1 (Data Pipeline):** Scraped 80 books, normalized INR pricing (1 GBP = 105.50 INR), stored in SQLite DB (`zepto_catalog.db`), verified via SQL JOIN and Pandas `pd.merge()`.
2. **Module 2 (Analytics):** Performed data cleaning, imputed missing values, trained Random Forest model for delivery time prediction.
3. **Module 3 (Support Assistant):** Grounded Support Assistant trained on 8 Zepto Policy text files.
